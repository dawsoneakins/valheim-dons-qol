# Don's QOL v0.5.1 release notes

## [0.5.1] - 2026-11-07

A fix release for 0.5.0. Everyone playing together needs the same version, so update as a group. Your settings, chest categories, favourites and saves carry over.

### Fixed

- **The world no longer turns brighter after you open the inventory.** The light for the character view's 3D model lit the whole world, and it stayed on after the inventory closed. It now lights only the character view.
- **The mod's panels now match the inventory.** The character menu, the Don's QOL menu, Base management, the Compendium, feed panels and the category dropdown use the inventory's own wood instead of a lighter one.
