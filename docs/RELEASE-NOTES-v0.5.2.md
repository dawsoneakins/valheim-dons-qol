# Don's QOL v0.5.2 release notes

## [0.5.2] - 2026-11-07

A fix release. Everyone playing together needs the same version, so update as a group. Your settings, chest categories, favourites and saves carry over.

### Fixed

- **The character menu no longer covers the game's own dialogs.** It hides while the split stack, item style, skills or texts dialog is open, and comes back when the dialog closes.
